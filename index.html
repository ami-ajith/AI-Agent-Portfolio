Weekly Support Case Dashboard

A weekly case-watch dashboard for a watched account, fed live from Salesforce, our CRM platform, where customer accounts and support cases are tracked. It shows the state of the week at a glance and flags the cases that need attention before they become escalations.

  • Headline counts: active cases, at risk, escalated, waiting on Infoblox, waiting on customer, resolution provided, closed this week.
  • Every active case is sorted automatically into Risk, Watchlist or Healthy, with reasons such as an open escalation or a case aging past 30 days.
  • Each row shows status, severity, Jira link, escalation flag and how long the case has been open, and expands to explain the case.

Built with Glean, Salesforce data · Time saved about 40 to 60 minutes per run, sometimes more

Customer Tiering Agent (Rolling 12-Month Closed-Won)

Companies group customers into tiers so teams know how much attention each account needs. This agent does that automatically. Give it a list of customer names and it looks up the deals each customer has signed in the last 12 months (called “closed-won” deals) in Salesforce, our CRM platform, adds them up, and labels every customer with a tier, from Prospect (nothing bought yet) up to Premier (the largest customers). Someone used to look up each account and add up the deals by hand.

  • Input: paste customer names, one per line, spelled exactly as they appear in Salesforce. Many customers can be checked in one run.
  • Step 1: a SOQL query (Salesforce’s query language, similar to SQL) totals each customer’s closed-won deal value over the past 12 months.
  • Step 2: the agent applies the tier bands (for example, $0 is Prospect and $1 to $99.9k is Growth) and returns the result.
  • Output: a table with each customer, their 12-month total and their tier (Prospect, Growth, Key, Strategic or Premier), ready to download to Excel.

Built with Glean agent builder, SOQL, Salesforce · Time saved about 40 to 60 minutes per run, sometimes more

Escalation Request Records Agent

An agent that produces the escalation team’s monthly data in one run. The user only enters a start and end date, so any date range can be pulled on demand.

  • Six SOQL steps query escalation records, requestor details (name, title, country) and counts by status directly from Salesforce.
  • The final step formats everything into one report with escalation reason, geography, CAEP or non-CAEP membership, outcome, and totals approved and rejected.
  • Can run on a schedule, replacing the manual monthly data pull.

Built with Glean agent builder, SOQL, Salesforce · Time saved about 40 to 60 minutes per run, sometimes more
