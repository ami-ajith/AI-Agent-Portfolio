3. AI Agent Portfolio

I build AI agents that pull data straight from Salesforce, our CRM platform, and turn it into reports, dashboards and escalation signals the team can act on. Each project below saves about 40 to 60 minutes every time it runs, and sometimes more.

3.1 Weekly Support Case Dashboard

A weekly case-watch dashboard for a watched account, fed live from Salesforce. It shows the state of the week at a glance and flags the cases that need attention before they become escalations.

  • Headline counts: active cases, at risk, escalated, waiting on Infoblox, waiting on customer, resolution provided, closed this week.
  • Every active case is sorted automatically into Risk, Watchlist or Healthy, with reasons such as an open escalation or a case aging past 30 days.
  • Each row shows status, severity, Jira link, escalation flag and how long the case has been open, and expands to explain the case.

Built with Glean, Salesforce data

3.2 Customer Tiering Agent (Rolling 12-Month Closed-Won)

Give the agent a list of customer names and it totals the closed-won deals each customer signed in the last 12 months in Salesforce, then labels every customer with a tier, from Prospect (nothing bought yet) up to Premier (the largest customers). Someone used to look up each account and add up the deals by hand.

  • Input: customer names, one per line, spelled exactly as they appear in Salesforce. Many customers can be checked in one run.
  • Step 1: a SOQL query totals each customer’s closed-won deal value over the past 12 months.
  • Step 2: the agent applies the tier bands (for example, $0 is Prospect and $1 to $99.9k is Growth) and returns the result.
  • Output: a table with each customer, their 12-month total and their tier (Prospect, Growth, Key, Strategic or Premier), ready to download to Excel.

Built with Glean agent builder, SOQL, Salesforce

3.3 Escalation Request Records Agent

An agent that produces the escalation team’s monthly data in one run. The user only enters a start and end date, so any date range can be pulled on demand.

  • Six SOQL steps query escalation records, requestor details (name, title, country) and counts by status directly from Salesforce.
  • The final step formats everything into one report with escalation reason, geography, CAEP or non-CAEP membership, outcome, and totals approved and rejected.
  • Can run on a schedule, replacing the manual monthly data pull.

Built with Glean agent builder, SOQL, Salesforce
